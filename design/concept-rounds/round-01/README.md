# Concept round 01 — style exploration

## Summary

The first round sets the basic look and sound of the game: the player ship, the palette, how
parallax scenes and the HUD look, the working title, the first sound effects, the music style
and the direction of the story twist. Open [index.html](index.html) in a browser to see and hear
everything side by side (regenerate it with `python3 tools/concept/board.py 01`).

All mockups are generated by code in `tools/concept/`. They show *direction*, not final
quality; each item also has a prompt in its part's `concept/prompts.md` for making polished
versions with an image or audio generator.
