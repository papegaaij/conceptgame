# Scatter Vulcan

## Summary

Rotary cannon firing a widening fan. Clears swarms and wide formations; weak against a single armoured target.

### Behaviour

- One volley = one fan from the front muzzle; bullets fade out at the end of their 490 px range (0.7 s).
- From L4 the fan has a dense core (±3–11°) plus wider flankers, so single-target damage still grows per level.
- One sound per volley, not per bullet (see the `vulcan` family).
