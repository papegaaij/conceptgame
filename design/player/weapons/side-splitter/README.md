# Side Splitter

## Summary

Rear-slot gun that fires sideways, left and right at once. Covers enemies that hold at the screen edges.

## Design

| Property | Value |
|---|---|
| Slot | Rear gun |
| Traits | `side` |
| Layers hit | `air`, `low-air` and `ground` (hardened ground targets glance off); not `high-air`; the `sub` layer only in under-water mode, at 50 % ([layer rules](../../../enemies/README.md#layer-rules)) |
| Price | 1 400 cr |
| Upgrade cost L2 / L3 / L4 / L5 | 700 / 1 400 / 2 800 / 5 600 cr (sell-back per [economy](../../../systems/economy/README.md)) |

### Behaviour

- Fires from both wing roots at 90° left and 90° right at the same time; the table lists one side.
- Range 360 px (0.45 s), enough to reach either edge from the centre of the 480 px play field.
- Takes the rear slot: choosing it means flying without a rear gun.
