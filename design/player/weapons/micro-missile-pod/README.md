# Micro-missile Pod

## Summary

Wing pod firing small homing missiles that curve out and in. The first homing weapon (L06).

## Design

| Property | Value |
|---|---|
| Slot | Wing mount (per pod) |
| Traits | `homing` |
| Layers hit | `air`, `low-air`, `ground` (hardened targets glance off) and **`high-air`** ([layer rules](../../../enemies/README.md#layer-rules)) |

### Behaviour

- Per pod: missiles launch outward at 30° (left pod to the left, right pod to the right), then home.
- Each missile picks the nearest hittable enemy (incl. `high-air`) within 350 px in a 140° cone ahead; re-acquires on target loss; lifetime 1.2 s; speed 500 px/s.
- Turn rate as listed (+20 % with the targeting computer).
