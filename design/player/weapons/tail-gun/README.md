# Tail Gun

## Summary

The basic rear gun: straight bolts backwards for enemies that come from behind.

## Design

| Property | Value |
|---|---|
| Slot | Rear gun |
| Traits | `rear` |
| Layers hit | `air`, `low-air` and `ground` (hardened ground targets glance off); not `high-air`; the `sub` layer only in under-water mode, at 50 % ([layer rules](../../../enemies/README.md#layer-rules)) |
| Price | 600 cr |
| Upgrade cost L2 / L3 / L4 / L5 | 300 / 600 / 1 200 / 2 400 cr (sell-back per [economy](../../../systems/economy/README.md)) |
| Unlock | L08 (in the shop from the hangar visit before it) |
| Projectile | 800 px/s, 4×10 px, range until off-screen |
| Sound family | `pulse` ([weapon sound families](../../../audio/sfx/README.md#weapon-sound-families)) |
| Projectile family (VFX) | `pulse` (projectile sheet of concept round 08) |

### Behaviour

- Bolts leave the rear muzzle (24, 45) straight down and fly until they leave the screen.
- Plays the `pulse` family about 10 % lower than the front gun.
