# Design review — Acts 1–2

## Summary

The final approval of everything needed to implement Acts 1–2 (levels 01–14), as the first
playable part of the game. 110 documents in 8 groups, all set to `design: review`
(✓ = already approved). Review per group: approve it, or comment and it gets reworked. Approved
documents get `design: approved`; only the user approves.

Not in scope: Acts 3–7, their settings and the tech stack (a separate evaluation).

## How to review

- Every document has an **Implementation** checklist (the ticket) and **Decisions** log; the
  concept art it relies on is linked from its Concept art table or Design notes.
- `python3 tools/check_docs.py` validates the structure; `python3 tools/balance.py` checks the
  economy and damage curve for levels 01–14 (the L01–L03 onboarding gap is accepted).
