# Main menu

## Summary

The title screen and main menu. The user asked for new game (easy / medium / hard), load game
and quit. This draft adds **Continue**, **Options** and **Credits**: Continue saves a trip
through the slot list, Options is needed for audio volumes and control remapping, and Credits is
genre-standard.

## Design

### Title screen

A pre-rendered scene: the Stormhawk banking past Earth with the Vrell fleet emerging from the
dark, the *Terran Vanguard* logo ([concept/logo-r01-d.png](concept/logo-r01-d.png)), and "PRESS START". Title music starts. After 30 s idle it could play an
attract-mode demo (open question).

### Menu

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                              │

│                                OPTIONS                                       │
│                                CREDITS                                       │

│                                                                              │
│                                                                              │
│  v0.1                                               © 2185 UTC Defence Force │
└──────────────────────────────────────────────────────────────────────────────┘
```

| Item | Behaviour | Requested by user |
|---|---|---|
| Continue | Loads the most recent save. Hidden when no save exists | added |
| New game | Difficulty select: Easy / Medium / Hard with a one-line description each, then the intro briefing | yes |
| Load game | Slot list (8 manual + autosave), see [saves](../../systems/saves/README.md) | yes |
| Options | Audio (music, SFX, radio volume), controls ([remapping](../controls/README.md)), display (fullscreen, scale, optional CRT/scanline filter) | added |
| Credits | Scrolling credits over the credits music | added |
| Quit | Confirmation, then exit | yes |

Difficulty descriptions (draft):
- **Easy**: "Recruit. Forgiving fire, free repairs, generous pay."
- **Medium**: "Pilot. The war as it was meant to be fought."
- **Hard**: "Ace. Denser fire, costly repairs, three retries per mission."
